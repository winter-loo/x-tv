# 局域网辅助登录

此功能在当前开发版本中提供，尚未包含在 GitHub 上已发布的 0.2.0 APK 中。

投影仪运行一个 10 分钟有效的临时 HTTP 服务。手机扫码后自动配对，手机键盘的输入会直接写入投影仪当前获得焦点的输入框。X / Google 登录页面仍在投影仪上运行，登录态由投影仪的 Gecko 保存；手机已有的登录态不会被复制，也不需要 X 开发者账号。

## 使用

1. 让手机与投影仪连接同一局域网，在原生登录入口选择「用手机辅助登录」；也可在认证网页按菜单键选择「手机辅助输入」。
2. 用手机扫描投影仪上的二维码。二维码包含当前局域网地址和一次性配对码，网页打开后会自动配对，不需要再输入或确认配对码。
3. 配对后在电视画面下方的「手机输入」框输入，文字会实时出现在电视当前输入框。按手机键盘的回车键在电视上确认。
4. 如果电视焦点不在所需输入框，点手机上的电视画面选中目标输入框，手机键盘会随即获得焦点。登录完成后以投影仪显示的结果为准。

二维码无法识别时，可以在手机浏览器手动打开投影仪显示的完整 HTTP 地址，再输入备用的 8 位配对码。

## 输入行为

- 普通文字、密码、验证码和手机输入法最终选中的中文会直接同步，不需要「发送文字」按钮。
- 退格、自动纠错和候选词替换会作为一次删除加插入操作发给电视，避免重复内容。
- 输入与按键严格顺序执行；确认成功后手机输入框会清空并保持焦点，便于继续填写下一项。
- 如果一次同步无法确认，手机会保留当前内容并停止继续编辑。重新点一次远端画面中的目标输入框后再输入，可以建立新的同步起点；系统不会在结果不确定时自动重发敏感文字。

## 边界

- 每次开启仅允许一个浏览器配对；配对码输错 5 次后需要重新开启。浏览器刷新会丢失只存在内存中的连接凭证。
- 二维码里的配对码位于 URL fragment，浏览器首次请求不会把它放进 HTTP 请求路径；配对完成后页面会立即清除地址栏里的 fragment。连接令牌和输入内容不写入浏览器存储或应用日志。
- 页面只发送画面、点击和输入；不提供 Cookie 导出、任意脚本执行或浏览器调试端口。
- 局域网连接使用 HTTP，不需要证书；画面和输入以明文传输，请在可信网络中使用。服务只绑定当前网络的私有 IPv4 地址，应用退到后台、用户返回、登录验证成功、手动结束或超过 10 分钟都会撤销连接。
- 访客网络隔离、VPN 或无法互访的 Wi-Fi 会阻止连接。辅助输入不能绕过 X / Google 的验证码、设备检查或登录限制。
