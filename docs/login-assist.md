# 局域网辅助登录（原型）

此功能在当前开发版本中提供，尚未包含在 GitHub 上已发布的 0.2.0 APK 中。

投影仪运行临时 HTTPS 服务，把投影仪 GeckoView 当前画面发送给配对的浏览器，并接收点击、文字和按键。X / Google 登录页面仍在投影仪上运行，登录态由投影仪的 Gecko 保存。电脑或手机已有的登录态不会自动同步，也不需要 X 开发者账号。

## 使用

1. 让手机或电脑与投影仪连接同一局域网。在 X TV 登录页选择「手机 / 电脑辅助登录」。
2. 在电脑或手机浏览器输入投影仪显示的完整 `https://IP:端口` 地址。原型使用地址和配对码，暂未生成二维码。
3. 浏览器会提示本地证书不受信任：先查看证书的 SHA-256 指纹，与投影仪显示的完整指纹核对，再继续访问。无法查看或核对证书的浏览器不适合此原型；可以使用电脑浏览器。无需把证书安装为系统信任根。
4. 输入投影仪上的 8 位配对码。点击远端画面选中输入框，然后在下方输入并发送文字；密码和验证码也通过这个输入框发送。发送成功后会清空辅助输入框；失败时保留文字并显示错误，确认焦点后可重试。输入后使用「确认」或点击画面中的按钮继续。
5. 登录完成后看投影仪确认结果。服务会在识别到 X 已登录账号导航、10 分钟到期、投影仪返回键或应用退到后台时关闭。也可点击远端「结束连接」。

## 边界

- 每次开启仅允许一个浏览器配对；配对码输错 5 次后需要重新开启。浏览器刷新会丢失内存中的连接凭证，需要在投影仪停止后重新开启。
- 页面只发送画面、点击和输入；不提供 Cookie 导出、任意脚本执行或浏览器调试端口。文字和连接令牌不写入日志或浏览器存储。
- HTTPS 身份由设备 Android Keystore 单独生成；与 APK 长期分发签名完全独立。服务只绑定当前网络的私有 IPv4 地址，不在后台常驻。
- 当前只验证局域网 IPv4；访客网络隔离、VPN、无法互访的 Wi-Fi 会阻止连接。尚未做二维码、自动发现、连续视频串流或多客户端控制。
- 这改善的是远程输入，不能保证 X / Google 接受设备上的每次登录。验证码、设备检查和平台登录限制仍可能出现。远端连接断开不一定代表登录成功，应以投影仪为准。
