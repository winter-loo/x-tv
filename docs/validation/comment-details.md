# 评论详情 — 2026-09-08

## 行为

- 右键进入评论栏，上下选择评论，确认按该评论自己的永久链接打开详情。长评论先翻阅，再换下一条；到已加载列表末尾继续触发 X 原生分页。
- 评论焦点按 canonical status 路径保存。同一评论的 DOM 替换仍保持选中；节点被回收成另一条评论时，确认不会误打开它。
- 编辑历史链接还原为评论本身的路径，引用帖身份不会被当作该评论身份。出现在当前评论之前的上级帖子不列入子评论。
- Native Gecko 会话栈保留首页和各层详情。Back 先取消编辑或弹层，再关闭当前会话，恢复上一层；系统输入法显示时先收起键盘。加载中 Back 也只退出当前层。
- 评论栏再次按右键到“写评论”；取消输入后仍留在当前详情。实机验证只打开/取消空输入框，不发布内容。
