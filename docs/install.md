# X TV 0.2.1 试用安装说明

X TV 是面向遥控器的非官方 X 阅读客户端。试用包：`X-TV-0.2.1-armeabi-v7a.apk`。

## 支持设备

- 系统要求：Android 9（API 28）及以上，支持 `armeabi-v7a`（32 位 ARM）应用的电视、电视盒子或投影仪。
- 已实测：当贝 DBD5X Pro，Android 9、1920×1080。当前真机阅读与遥控器回归使用 Debug 构建；长期签名版的首次安装及登录仍待实测。
- 64 位 ARM 设备只有保留 32 位应用兼容能力才能安装；纯 64 位 ARM、x86、Apple TV、非 Android 电视系统不支持当前 APK。
- 其他品牌、分辨率和较新 Android 系统尚未实测，满足最低要求不代表已验证兼容。
- 需要可访问 X 的网络、自己的 X 账号，以及带方向键、确认和返回键的遥控器。

## 安装

### U 盘或设备文件管理器

1. 获取上述 APK；如提供 `SHA256SUMS`，可在电脑同目录运行 `sha256sum -c SHA256SUMS` 校验。
2. 将 APK 复制到 U 盘或传到设备，在设备的文件管理器中打开。
3. 按系统提示允许该文件管理器“安装未知应用”，然后安装。入口名称随设备系统不同。
4. 从应用列表打开 X TV，按页面引导登录 X，再用遥控器浏览。

### ADB 安装

在设备开启开发者选项和 USB / 网络调试，并确认电脑的调试授权。网络调试地址以设备显示为准：

```sh
adb connect <设备IP:调试端口>
adb devices
adb -s <设备序列号或IP:端口> install -r X-TV-0.2.1-armeabi-v7a.apk
```

USB 连接可跳过 `adb connect`。若系统提示 ABI 不匹配，说明设备不能运行当前 32 位 ARM 包。

## 升级与旧开发版迁移

以后从同一长期签名发布的版本可覆盖安装，保留应用数据；版本升级会递增 versionCode。

如果已装 `0.2.0-debug` 等开发版，签名不同会导致覆盖失败（如 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`）。这不是 APK 损坏。迁移通常需要先卸载开发版，再安装试用版，**卸载会清除本地登录和应用数据，需要重新登录**；准备好账号登录方式后再自行操作。当前没有自动迁移工具。

## 遥控器基本操作

- 时间线正文按确认：进入帖子详情；返回：直接回到原时间线位置。
- 详情正文再次按确认：进入全屏阅读；返回：恢复详情。
- 上下键阅读或切换帖子；右键进入媒体或评论区域。
- 菜单键打开帖子操作；关注入口在作者简介页。

## 已知问题与试用边界

- 作者页只汇总当前已加载的帖子，不是作者完整历史。
- X 网页和接口变化可能导致登录、加载、评论或关注等功能暂时失效。
- Apple、用户名密码等登录路径尚未完成全面验收；长期签名包首次登录仍待真机验证。
- 不同设备的系统 WebView、遥控器键值和显示缩放可能存在差异；当前主要按当贝投影仪 1080p 调整。
- 当前包仅含 32 位 ARM，体积约 159 MiB；未提供应用商店版本或应用内自动更新，请手动下载后续 APK。
